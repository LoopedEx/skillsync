💡 Clarifications You Asked:
-----------------------------

**Q: How to parse resumes?**
- Start simple: if PDF or text, extract basic data (skills, education, experience).
- Use `pdf-parse` for PDFs or just read text uploads.
- Then run simple keyword matching for skills.

**Q: How to show mini preview of resume?**
- When a user uploads a file, display:
  - Either file name + download button
  - Or use `<iframe src={fileUrl} />` if you want to preview PDF inside the page.

**Q: Where to store resumes?**
- Save file to `/backend/uploads/` folder.
- Save file path in MongoDB under user's Resume model.

Example MongoDB Resume schema:
```javascript
const ResumeSchema = new mongoose.Schema({
  userId: { type: mongoose.Schema.Types.ObjectId, ref: 'User' },
  filename: String,
  filepath: String,
  extractedSkills: [String],
  createdAt: { type: Date, default: Date.now }
});
```

## 💬 Details

**Resume Parsing**
- User uploads PDF
- Django saves it in `/media/`
- `pdfminer` / `pdfplumber` reads the file
- Extract skills, education using regex/keywords
- Save parsed data to the database

**Mini Resume Preview**
- Get resume URL after upload
- In React, render using:
```jsx
<iframe src={uploaded_resume_url} />
```

**Storing Resumes**
- `MEDIA_ROOT = /backend/media/`
- `MEDIA_URL = /media/`
- Use Django's static/media file settings

Example Resume model:
```python
class Resume(models.Model):
    user = models.ForeignKey(User, on_delete=models.CASCADE)
    file = models.FileField(upload_to='resumes/')
    extracted_skills = models.JSONField(default=list)
    created_at = models.DateTimeField(auto_now_add=True)
```
